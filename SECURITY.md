# Security policy

If you find a security problem (for example a way to crash the game server, join rooms you shouldn't, or cheat against other players), please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/nick10-05/cricketverse/security/advisories/new).

Please include steps to reproduce. You'll get a reply as soon as possible, and credit in the fix if you want it.

The game stores no accounts, passwords or personal data on the server. Match history lives only in each player's browser.
